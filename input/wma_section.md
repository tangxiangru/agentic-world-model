## The recorder agent
A recorder agent runs beside you in this session as another Claude Code session — `ListAgents` shows it; its name starts with `wma`. It keeps the reproducible record of your experiments and can be reached at any time with the `SendMessage` tool. It is a scribe, not an advisor: it has no knowledge of past attempts at this task, it never trains or evaluates anything, it never suggests what to try, and asking it for opinions or predictions is pointless — it will only answer that it keeps the record. Explore on your own judgment.

Message it at three moments. **Before each training or model-producing launch**: what you are addressing, the exact command, the data and where it comes from, which checkpoint you start from, and how you will evaluate. **After each evaluation or failure**: the numbers with the eval output file path, or the error and its log. **When you are done**: what you shipped and its score. It may reply with up to three questions when the record is missing something it cannot read from your files — answer them; a recorded experiment other people can rerun is part of your job. It does not message you unless you message it. Talking to it is not user interaction.
